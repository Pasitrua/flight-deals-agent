# Flight Deals Agent (Moscow → Asia & Middle East)

Ежедневный GitHub Actions-агент, который:
- ищет билеты туда-обратно из Москвы;
- рассматривает Азию и Ближний Восток;
- бюджет до €1000;
- эконом-класс;
- максимум 1 пересадка;
- показывает варианты, где доступно минимум 3 места (если источник предоставляет это поле);
- сохраняет историю цен и отмечает снижения;
- отправляет отчёт в Telegram.

## Важно

Проект использует API-провайдера авиапоиска через адаптер. В стартовой версии предусмотрен адаптер Amadeus Self-Service API. Для реального поиска нужно создать API-ключи у провайдера и проверить его актуальные ограничения, покрытие маршрутов и условия использования.

Агент **не гарантирует** полноту рынка и не обходит CAPTCHA/защиты сайтов. Цены и наличие берутся только из ответа API.

## Быстрый запуск

1. Создайте публичный или приватный GitHub repository.
2. Загрузите файлы проекта.
3. В GitHub откройте `Settings → Secrets and variables → Actions`.
4. Добавьте secrets:
   - `TELEGRAM_BOT_TOKEN` — токен BotFather.
   - `TELEGRAM_CHAT_ID` — ваш chat ID.
   - `AMADEUS_CLIENT_ID` — client ID API.
   - `AMADEUS_CLIENT_SECRET` — client secret API.
5. В `Settings → Actions → General` разрешите workflow.
6. Откройте `Actions → Daily flight deals → Run workflow` для тестового запуска.

Токены не помещайте в код, README или логи.

## Расписание

Workflow запускается ежедневно в 07:15 по Москве с учётом UTC+3 в текущем расписании (`04:15 UTC`). GitHub может задерживать scheduled runs. Время можно изменить в `.github/workflows/daily.yml`.

## Ограничения MVP

- Список направлений задаётся в `src/config.py`.
- Чтобы не создавать чрезмерную нагрузку, запросы ограничены небольшим набором направлений и дат.
- Для настоящего поиска «любые даты» используется сканирование ближайших 180 дней с шагом 7 дней; это можно расширить, учитывая лимиты API.
- Даты и цены в отчёте — результат фактического ответа API.
