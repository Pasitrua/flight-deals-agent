# Moscow Flight Deals → Telegram (Aviasales Data API)

Ежедневный GitHub Actions-бот для поиска round-trip билетов из Москвы в Азию и на Ближний Восток через Aviasales Data API.

## Условия
- Москва (MOW)
- Азия + Ближний Восток
- туда-обратно
- 3–5 дней
- эконом
- максимум 1 пересадка
- до 20 000 ₽ за round trip
- минимум 3 доступных билета — только если API реально возвращает количество мест
- ежедневный запуск
- Telegram-отчёт

## Важное ограничение
Aviasales Data API работает с кэшированными данными истории поисков, а не с гарантированным live-search. Поэтому бот явно указывает это в отчёте.

## GitHub Secrets
Добавьте:
- `AVIASALES_API_TOKEN`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

## Как работает
Используется `https://api.travelpayouts.com/aviasales/v3/get_latest_prices` с `trip_class=0` (эконом), RUB и набором направлений из `src/config.py`.

Затем бот фильтрует:
- 3–5 дней
- ≤ 20 000 ₽
- ≤ 1 пересадка
- эконом
- минимум 3 места, если поле реально присутствует.

Если Aviasales не возвращает количество доступных мест, предложение НЕ считается подтверждённым и не отправляется как подходящее. Бот ничего не выдумывает.

Workflow запускается ежедневно в 15:00 UTC (18:00 Москва при UTC+3) и вручную через GitHub Actions.

Не помещайте API token в исходный код.
